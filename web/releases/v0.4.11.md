**开途 0.4.11 重点更新**：修复了 Windows 桌面从旧版本自动更新时可能陷入反复重装、界面版本与实际不一致的问题；并改进了跨境线路在丢包时的传输通道切换——不再出现「显示已连接，AI 工具或网页却一直打不开」的情况。

## Bug Fixes

- **修复 Windows 桌面自动更新可能反复重装**：0.4.9 起，部分 Windows 用户在自动更新时，安装程序无法覆盖仍在运行的程序文件，会陷入「装好又回退、反复重装」的循环，界面显示的版本与实际运行的不一致。现在安装程序会在覆盖前可靠地释放旧程序，自动更新恢复正常
- **修复跨境线路丢包时应用打不开**：当移动网络对跨境 UDP 流量限速或丢包时，隧道可能卡在一条已经不通的传输通道上，表现为「显示已连接，但 AI 工具、网页一直转圈打不开」。现在会更快识别这种情况并自动切换到更稳的备用传输通道
