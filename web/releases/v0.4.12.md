**开途 0.4.12 重点更新**：换上了开途新 logo；修复了点击连接时卡顿、桌面端首次连接偶发失败、部分网页或下载结尾数据丢失的问题；按应用分流在 macOS / Windows 上识别更准确。

## New Features

- **开途新 logo**：全平台图标换成新 logo。升级后 Windows 的桌面 / 开始菜单快捷方式、已钉在任务栏的图标，以及 macOS 的 Dock 图标都会自动换新
- **分流国家可搜索**：选择分流国家时可以直接输入搜索，不用在长列表里翻找
- **注销账号三步确认**：注销前会逐步确认，并醒目列出将会失去的会员时长等资产，避免误操作

## Bug Fixes

- **修复点击连接时卡顿**：连接过程中不再联网拉取规则，规则只在真正有变化时才重新加载，连接更快更稳
- **修复桌面端首次连接偶发失败**：新安装或缓存被清空后第一次连接，不再因规则尚未下载完成而报错
- **修复部分网页或下载结尾数据丢失**：连接关闭时，已经收到但尚未交给应用的最后一段数据不再被丢弃，网页显示不全、下载文件不完整的情况得到修复
- **修复本机环境问题被误报为「更换节点」**：电脑本身创建虚拟网卡失败时，现在会提示「重启设备」，而不是让你去更换线路
- **修复手机上选择语言 / 分流国家时结果被键盘挡住**：搜索结果不再被弹出的键盘盖住、无法点选
- **修复 Windows 卸载后残留**：卸载后不再留下安装目录和开始菜单快捷方式

## Improvements

- **macOS 按应用分流更准确**：按应用目录识别应用；由系统服务代为发起的连接，也会正确归到真正发起请求的应用
- **Windows 按应用分流更准确**：经系统 DNS 解析发出的查询会归到发起它的应用，并按程序所在位置识别应用；旧版本保存的分应用设置升级后自动沿用
- **UDP 线路异常后自动恢复**：中转通道被判定不健康后会定期自动试探，网络恢复后不需要手动重连
- **专属线路页面更名为「我的路由器」**
