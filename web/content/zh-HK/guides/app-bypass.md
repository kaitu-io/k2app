開途最新一輪規則最佳化帶來兩項升級。第一，<strong>除 iPhone / iPad 外，電腦版（Mac / Windows / Linux）與 Android 現已支援按應用程式、甚至按程序精準分流</strong>，可以將任何一個 App 一鍵強制「直連」；第二，<strong>針對微信、QQ、騰訊文件、騰訊會議等騰訊系列應用程式進行了專項歸屬最佳化</strong>，徹底解決這類「怕換 IP」的應用程式在代理下被風控、登入失效、訊息延遲的老問題。常用應用程式清單由雲端持續更新，<strong>無需升級 App、無需重新連線即可生效</strong>。

## 一、按應用程式 / 程序分流：任何 App 一鍵直連（iPhone / iPad 除外）

「按應用程式分流」讓您為每個應用程式單獨決定走代理抑或直連。它有兩層：

- <strong>智能模式（預設啟用）</strong>：中國大陸應用程式——微信 / 支付寶 / 12306 / 主流銀行——自動直連，其餘流量走代理，開箱即用，無需手動配置。
- <strong>按應用程式手動覆蓋</strong>：將單一應用程式強制設定為「直連」，覆蓋當前區域的智能預設。適用於會因代理 IP 觸發網絡安全風險的銀行 App、網上遊戲等。
- <strong>電腦版支援到「程序」級別</strong>：除已安裝應用程式外，命令行工具、Homebrew / Node 等獨立程式也能作為候選出現（按程序名稱去重，自動過濾系統程序），分流粒度更細。
- <strong>私隱保障</strong>：分流配置中的應用程式名稱永遠不會出現在日誌、回饋包或錯誤上報中。

<strong>為何 iPhone / iPad 例外？</strong>iOS 系統不向 VPN 擴充功能開放「某條連線屬於哪個 App」的歸屬資訊，因此 Apple 裝置上無法按應用程式選擇。但智能分流的<strong>按域名 / IP 的規則分流在 iOS 上照常運作</strong>——境內網站及服務依然自動直連，只是不能精確到單一 App。

## 二、騰訊系列應用程式專項最佳化

騰訊系列應用程式對網絡出口格外敏感，過往在代理下最容易出現問題。是次我們進行了專項歸屬最佳化，<strong>已在 Mac / Windows / Linux / Android 真機逐一驗證</strong>。常見的幾類問題：

- <strong>微信換 IP 被風控</strong>：代理出口頻繁變化會觸發登入保護、掃描失效、支付異常。智能模式讓微信預設直連，使用您真實的本地 IP。
- <strong>QQ 多程序 / 子模組嵌套</strong>：QQ 將騰訊文件等子模組嵌入應用程式包內，過往歸屬會漏判，導致本應直連的子程序走了代理。現已正確識別。
- <strong>騰訊會議 / 騰訊視訊卡頓</strong>：這類應用程式走本地 CDN，繞過代理直連更快更穩定。
- <strong>Windows 上的 UDP / QUIC 漏歸屬</strong>：Windows 核心將這類 socket 記錄成萬用字元位址，過往會整類漏掉；現已按精確位址匹配修復。

效果是：微信、QQ、騰訊文件、騰訊會議等<strong>穩定直連，不再被代理 IP 拖累</strong>。如果您有特殊需求，亦可在「按應用程式分流」頁面手動將任何騰訊系列應用程式切換為「直連」或「智能」。

## 三、三步啟用按應用程式分流

1. 開啟開途客戶端，展開<strong>「進階設定」</strong>，將<strong>路由模式</strong>設定為<strong>「智能分流」</strong>（對應圖 1 的 ①）。
2. 在<strong>「分流地區」</strong>點選您所在的區域，例如「中國」，或者勾選「自動偵測 (根據 IP 位置)」(圖 1 的 ②)。
3. 點擊<strong>「不經代理程式的應用程式」</strong>進入列表 (圖 1 的 ③)。預設全部跟隨智能規則；需要時可將某個 App 切換為<strong>「直接連線」</strong>(圖 2 的 ④)。

提示：連線 VPN 期間進階設定為唯讀，<strong>先中斷連線再修改分流配置</strong>即可。

## 常見問題 (FAQ)

### Q：iPhone / iPad 為何不能按應用程式分流？

iOS 系統不向 VPN 延伸開放每條連線的應用程式歸屬資訊，這是 Apple 的系統限制，並非開途的功能缺失。Apple 裝置上仍可使用按網域名稱 / IP 的智能分流，本地網站和服務仍然自動直接連線。

### Q：將微信設成「直接連線」安全嗎？會洩露真實 IP 嗎？

直接連線意味著微信使用您本地的真實網絡連接騰訊伺服器，不經過代理程式——這正是微信期望的狀態，能避免更換 IP 觸發的風險控制。微信本來就直接連線騰訊自家伺服器，不存在額外私隱風險；反而強行經代理程式才更容易出問題。

### Q：「智能」和「直接連線」有何區別？

智能 = 跟隨目前區域的分流規則 (本地應用程式直接連線、其餘經代理程式)，由雲端規則庫決定。直接連線 = 強制這個 App 永遠不經代理程式。需要精確控制某個應用程式時使用「直接連線」，其餘保持「智能」即可。

### Q：新安裝的 App 需要重新連線才能生效嗎？

不需要。常用應用程式清單由雲端每小時自動重新整理，新安裝應用程式即時納入候選，分流即時生效，無需升級 App、也無需中斷重新連線。

### Q：電腦端的「按程序分流」是什麼意思？

除了圖形界面 App，電腦端還能識別命令行工具、Homebrew / Node 等沒有安裝記錄的獨立程序 (按程序名稱去重)。這樣像開發工具、腳本這類沒有傳統「App 圖標」的程序也能單獨分流。
