<strong>申請美區 Apple ID 最簡單嘅方法係用網頁申請：打開 account.apple.com，將「國家或地區」揀做美國，用一個從未申請過 Apple ID 嘅電郵完成驗證就得喇——全程唔使美國信用卡，本地手提電話號碼（+86）都用得。</strong>唯一硬性前提係申請嗰陣部電腦或者手提電話要喺純美利堅互聯網環境下，如果唔係 Apple 會用 IP 判定你嘅真實地區，搞到申請失敗或者付款方式度搵唔到「無（None）」。

下面係完整圖文嚮導。建議先睇「30 秒速覽」，再按住步驟逐步操作。

## 30 秒速覽：成個流程五步

1. <strong>① 準備</strong>：全新電郵 + 手提電話號碼 + 美國地址 + 美國互聯網（必需）
2. <strong>② 創戶</strong>：喺網頁 account.apple.com 創立帳戶，地區揀「美國」，驗證電郵同手提電話（必需）
3. <strong>③ 登入</strong>：喺 iPhone 嘅「App Store」度登入新帳戶（必需）
4. <strong>④ 設付款</strong>：下載任意免費應用程式，付款方式揀「無（None）」（必需）
5. <strong>⑤ 驗證</strong>：下載一個美區獨佔嘅免費應用程式確認成功（建議）

> <strong>關鍵認知</strong>：而家嘅網頁申請流程根本唔會問你要付款方式。付款方式設為「無」呢一步，發生喺你第一次喺 iPhone 上登入並下載免費應用程式嘅時候。明白呢一點，成個流程就唔會亂。

## 申請前嘅 4 樣準備

- <strong>電郵</strong>：從未申請過任何 Apple ID。用全新嘅 Gmail 或者 Outlook，盡量唔好用 QQ / 163（偶爾收唔到驗證電郵）。
- <strong>手提電話號碼</strong>：收倒短訊驗證碼就得。本地 +86 號碼用得，Apple 接受任何國家號碼做申請驗證。
- <strong>美國地址</strong>：一個真實存在嘅美國地址。揀免稅州（見下方清單），用「美國地址產生器」產生一份就得。
- <strong>美國網絡</strong>：申請時 IP 必須喺美國。用 [开途](/install) 連接到美國節點、開啟全域模式之後先申請。

### 點解「美國網絡」係硬門檻？

Apple 喺你瀏覽申請頁面同首次登入商店時，會用你嘅出口 IP 判定真實地區。如果 IP 仲喺本地：

- 申請頁可能直接彈出 "目前無法完成你嘅請求"；
- 就算創戶成功，付款方式都唔會出現「無（None）」選項，逼你綁咭。

所以申請嘅第一步唔係填表，而係先將互聯網環境準備好。先喺電腦（macOS / Windows）或者 Android 上安裝 [开途](/install) 並連接到美國節點 + 全域模式——桌面版可以直接官網下載安裝，唔依賴 App Store，正好解決「想申請美區 ID 但仲未有美區 ID 下應用程式」嘅雞生蛋問題。連接穩定後，全程保持開啟。

> <strong>小技巧</strong>：用瀏覽器嘅「無痕 / 隱身模式」打開申請頁，避免舊緩存將地區記做中國。

## 第一步：喺網頁創立帳戶（最關鍵嘅一步）

1. 喺已連接美國節點嘅裝置上，用無痕視窗打開 account.apple.com。
2. 點擊右上角「建立你嘅 Apple 帳戶 / Create Your Apple Account」。
3. <strong>國家或地區務必揀「美國 / United States」</strong>；姓名填英文名（拼音就得）；出生日期建議設為 18 歲以上；電郵填全新電郵；手提電話號碼填本地 +86 就得。
4. 點擊「繼續」，分別完成電郵驗證碼同手提電話短訊驗證碼兩步驗證。

完成後帳戶就建立好喇。<strong>注意：網頁呢一步全程唔會要求你填付款方式或者信用卡</strong>，呢個係正常嘅。

> 官方流程參考：Apple 支援文件《點樣建立新嘅 Apple 帳戶》。網頁建立淨係需要電郵、地區、生日、手提電話四要素。

## 第二步：喺 iPhone 上登入（淨係登入 App Store，唔好登入 iCloud）

呢一步有個保命原則：<strong>新註冊嘅美區 Apple ID 請淨係登入「App Store」，千祈唔好登入 iCloud（設定最頂嗰個）。</strong>因為跨區賬號有機會畀系統鎖定，一旦你喺 iCloud 度登入咗，賬號被鎖時手機可能冇辦法正常登出。

1. 打開 iPhone「設定」，撳最頂你個名 →「媒體與購買項目」→「登出」（首先登出目前嘅 Apple ID，呢一步唔會註銷 iCloud）。
2. 登出之後，喺同一個位置撳「登入」，輸入啱啱註冊嘅美區 Apple ID 賬號同密碼。
3. 如果提示雙重驗證，請依照短訊驗證碼完成。

呢個時候你已經用美區 Apple ID 登入咗商店，但賬號仲未喺 iTunes Store「激活」，所以要進行下一步。

## 第三步：將付款方式設為「無（None）」

呢個係好多教學都搞到人卡關嘅地方。<strong>Apple 已經取消咗喺「付款與配送」設定度直接揀「無」嘅入口</strong>，但「無」嘅選項會喺兩個場景下自動出現。建議用方法 A，最穩陣。

### 方法 A（建議）：透過「下載免費 App」觸發

1. 打開 App Store，隨便搵一個<strong>免費</strong> App，撳「取得 / Get」。
2. 系統會彈出 "此 Apple ID 尚未在 iTunes Store 使用過" → 撳「檢查 / Review」。
3. 進入帳戶資訊頁，呢個時候<strong>「付款方式」一欄會出現「無 / None」</strong>——選取佢。
4. 向下填寫賬單地址：用準備好嘅美國免稅州地址，電話填美國格式嘅 10 位號碼（地址產生器度會一齊畀，亂填都得）。
5. 同意條款，撳完成。

只要付款方式度出現咗「無」，就說明你嘅網路環境係乾淨嘅美國 IP，註冊成功有望。

### 方法 B（備用）：網頁更改地區觸發

如果方法 A 度冇出現「無」：

1. 回到網頁 account.apple.com →「個人資訊」→「國家或地區」。
2. 撳「更改國家或地區」→ 喺彈出嘅流程度重新確認選擇美國。
3. 去到付款步驟時，「無（None）」就會出現。填入免稅州地址就得。

> <strong>如果兩個方法都睇唔到「無」</strong>：99% 係網路環境問題。轉一個美國節點、確認開啟全局模式、清除快取或者轉用無痕視窗重試。呢個唔係賬號問題，係 IP 問題。

## 第四步：驗證是否成功

確認註冊真正可用嘅最直接方法，就係去下載一個美區獨佔嘅免費 App。如果可以正常下載並打開，就說明你嘅美區 Apple ID 已經完全可用。

之後想下載美區應用程式，只要保持 App Store 登入嗰個美區 Apple ID 就得；日常用 iCloud 仍然登入你原來嘅國區 / 本地 Apple ID，兩者互不影響。

## 美國免稅州地址快速查詢

填寫賬單地址時，強烈建議用「免稅州」嘅地址。美國有<strong>5 個州唔徵收州銷售稅</strong>，用呢啲州嘅地址，將來買收費 App 或者增值時可以慳到約<strong>6%–10%</strong>嘅稅費。

- <strong>俄勒岡（Oregon, OR）</strong>—— 最常用，地址資源多
- <strong>特拉華（Delaware, DE）</strong>—— 商業地址多
- <strong>蒙大拿（Montana, MT）</strong>
- <strong>新罕布什爾（New Hampshire, NH）</strong>
- <strong>阿拉斯加（Alaska, AK）</strong>—— 部分地方有市級稅

用任何「US address generator（美國地址產生器）」搵一份對應州嘅真實街道地址填入就得。地址淨係用嚟做賬單配對，唔會有任何實物寄送，所以填免稅州地址係完全安全嘅常規操作。

## 常見問題排查

- <strong>註冊頁彈出 "目前無法完成你的請求"</strong>：IP 唔喺美國 / 快取污染 → 轉美國節點、開全局模式、用無痕視窗、轉新電郵重試。
- <strong>付款方式度冇「無」</strong>：出口 IP 並非純正美國 IP → 更換節點確認落地美國、開啟全局模式後再次嘗試方法 A/B。
- <strong>收唔到電郵驗證碼</strong>：部分電郵被攔 → 改用 Gmail；檢查垃圾郵件箱。
- <strong>收唔到短訊驗證碼</strong>：營運商延遲 → 等幾分鐘後重發；+86 號碼本身係支援嘅。
- <strong>提示地區與付款方式唔符</strong>：地址唔係美國地址 → 賬單地址必須填寫美國（推薦免稅州）地址。
- <strong>登入後應用程式都仲係國區</strong>：App Store 仲未切換到美區 ID → 設定 → 媒體與購買項目 → 登出再登入美區 ID。

## 美區 ID 同國區 ID 有咩分別？

- <strong>App Store 地區</strong>：美區係美國商店，應用程式最齊全、最早上架；國區係中國大陸商店，部分應用程式缺失或者受限制。
- <strong>註冊門檻</strong>：美區需要美國網絡 + 美國地址；國區淨係需要國內手提電話號碼就得。
- <strong>付款方式</strong>：美區可以設定「無」或者用美區禮品卡增值；國區支援支付寶 / 微信。
- <strong>適用場景</strong>：美區適合下載海外獨有應用程式、搶先體驗；國區適合日常國內應用程式。

好多用戶嘅最佳實踐係：iCloud 用國區 ID 儲存相片同數據，App Store 用美區 ID 下載應用程式，兩套並行，各取所長。

## 常見問題（FAQ）

### 國內手提電話號碼可唔可以註冊美區 Apple ID？

可以。Apple 喺註冊驗證環節接受任何國家嘅手提電話號碼，國內 +86 號碼完全可以收到驗證碼、完成註冊。淨係喺第三步填寫賬單地址時，需要一個美國格式嘅電話號碼，而嗰個號碼可以隨便填（用美國地址生成器提供嘅就得）。

### 註冊美區 Apple ID 係咪一定要美國信用卡？

唔需要。只要喺第一次下載免費 App 時將付款方式設定為「無（None）」，就可以免信用卡使用。前提係註冊同登入時處於純正嘅美國網絡環境，否則「無」選項唔會出現。將來若果想買收費 App，可以購買美區禮品卡（App Store Gift Card）增值，同樣唔需要綁定信用卡。

### 美區 Apple ID 付款方式冇「無」選項點算？

呢個幾乎都係網絡環境問題，唔係賬號問題。請確認：① 裝置已連接到美國節點；② 開啟咗全局模式而唔係淨係分流；③ 用瀏覽器無痕視窗或者清除緩存後再試。用 [开途](/install) 連接穩定嘅美國節區係令「無」選項穩定出現嘅關鍵。

### 註冊美區 Apple ID 會唔會被封號？

正常註冊同使用唔會無故封號，但跨區賬號的確存在被風控嘅可能。降低風險嘅關鍵係：淨係喺 App Store 登入美區 ID，唔好登入 iCloud；保持登入時網絡環境穩定一致；唔好喺短時間內喺大量裝置上反覆登入同一個賬號。

### 註冊時係咪一定要全程開 VPN？

註冊同首次設定付款方式時必須開，因為 Apple 靠 IP 判定地區。賬號建立好、付款方式設定為「無」之後，日常下載美區免費應用程式時保持美國網絡會更穩妥，但短時間操作通常亦都可以完成。建議用 [开途](/install) 保持穩定連接，避免因為 IP 跳動而觸發風控。

### 已經有國區 ID 啦，仲可唔可以再註冊美區 ID？

可以。一個人可以擁有多個 Apple ID，只要每個 ID 用唔同嘅電郵註冊就得。推薦 iCloud 繼續用國區 ID，App Store 切換登入美區 ID 去下載應用程式。
