開途最新一輪規則優化帶來兩項升級。第一，<strong>除 iPhone / iPad 外，電腦版（Mac / Windows / Linux）與 Android 現已支援依應用程式，甚至依處理程序精準分流</strong>，可以將任意一個 App 一鍵強制「直連」；第二，<strong>針對微信、QQ、騰訊文件、騰訊會議等騰訊系列應用程式做了專項歸屬優化</strong>，徹底解決這類「怕換 IP」的應用程式在代理下被風控、登出、訊息延遲的老問題。常用應用程式清單由雲端持續更新，<strong>無需升級 App、無需重新連線即可生效</strong>。

## 一、依應用程式 / 處理程序分流：任意 App 一鍵直連（iPhone / iPad 除外）

「分應用程式分流」讓您為每個應用程式單獨決定走代理伺服器還是直連。它有兩層：

- <strong>智慧模式（預設啟用）</strong>：中國大陸應用程式——微信 / 支付寶 / 12306 / 主流銀行——自動走直連，其餘網路流量走代理伺服器，開箱即用，無須手動設定。
- <strong>依應用程式手動覆蓋</strong>：將單個應用程式強制設定為「直連」，覆蓋目前區域的智慧預設。適合會因代理伺服器 IP 觸發風險控管的銀行 App、線上遊戲等。
- <strong>電腦版支援「處理程序」級別</strong>：除已安裝應用程式外，命令列工具、Homebrew / Node 等獨立程式也能作為候選出現（依處理程序名稱去重複，自動過濾系統處理程序），分流粒度更細。
- <strong>隱私保護</strong>：分流設定中的應用程式名稱永遠不會出現在日誌、回饋包或錯誤回報中。

<strong>為什麼 iPhone / iPad 例外？</strong>iOS 系統不對 VPN 擴充功能開放「哪個連線屬於哪個 App」的歸屬資訊，因此 Apple 裝置上無法依應用程式選擇。但智慧分流的<strong>依網域名稱 / IP 的規則分流在 iOS 上照常運作</strong>——國內網站和服務依然自動直連，只是無法精確到單個 App。

## 二、騰訊系列應用程式專項優化

騰訊系列應用程式對網路出口格外敏感，過去透過代理伺服器最容易出問題。這次我們做了專項歸屬優化，<strong>已在 Mac / Windows / Linux / Android 真機逐一驗證</strong>。常見的幾類問題：

- <strong>微信換 IP 被風控</strong>：代理伺服器出口頻繁變化會觸發登入保護、掃碼失效、支付異常。智慧模式讓微信預設直連，使用您真實的本地 IP。
- <strong>QQ 多處理程序 / 子模組嵌套</strong>：QQ 將騰訊文件等子模組嵌入在應用程式包內，過去歸屬會漏判，導致本該直連的子處理程序走了代理伺服器。現已正確識別。
- <strong>騰訊會議 / 騰訊影片卡頓</strong>：這類應用程式走國內 CDN，繞過代理伺服器直連更快更穩定。
- <strong>Windows 上的 UDP / QUIC 漏歸屬</strong>：Windows 核心將這類 socket 記錄成萬用字元位址，過去會整類漏掉；現已依精確位址比對修復。

效果是：微信、QQ、騰訊文件、騰訊會議等<strong>穩定走直連，不再被代理 IP 拖累</strong>。如果您有特殊需求，也可以在「分應用程式分流」頁面手動將任意騰訊系列應用程式切換為「直連」或「智慧」。

## 三、三步驟開啟分應用程式分流

1. 開啟開途用戶端，展開<strong>「進階設定」</strong>，將<strong>路由模式</strong>設定為<strong>「智慧分流」</strong>（對應圖 1 的 ①）。
2. 在<strong>「分流國家」</strong>選擇您所在的區域，例如「中國」，或勾選「自動偵測（依據 IP 位置）」（圖 1 的 ②）。
3. 點選「不走代理的應用」進入清單（圖 1 的 ③）。預設全部遵循智慧型規則；需要時將某個 App 切換到「直接連線」（圖 2 的 ④）。<strong>提示：連線 VPN 期間，進階設定為唯讀，請先中斷連線再修改分流配置即可。</strong>常見問題（FAQ）<strong>Q：iPhone / iPad 為什麼不能依據應用程式分流？</strong>iOS 系統不向 VPN 擴充功能開放每條連線的應用程式歸屬資訊，這是 Apple 的系統限制，並非 Overleap 的功能缺陷。Apple 裝置上仍可使用依據網域 / IP 的智慧型分流，臺灣網站和服務仍會自動直接連線。

Q：將微信設為「直接連線」安全嗎？會暴露真實 IP 嗎？<strong>直接連線意味著微信使用您本地的真實網路連線騰訊伺服器，不經過代理——這正是微信期望的狀態，能避免更換 IP 觸發的風險控制。微信本來就直接連線騰訊自家伺服器，不存在額外隱私風險；反而強制透過代理更容易出問題。</strong>Q：「智慧型」和「直接連線」有什麼區別？

## 智慧型 = 遵循目前區域的分流規則（臺灣應用程式直接連線、其餘透過代理），由雲端規則庫決定。直接連線 = 強制這個 App 永遠不透過代理。需要精確控制某個應用程式時使用「直接連線」，其餘保持「智慧型」即可。

### Q：新安裝的 App 需要重新連線才能生效嗎？

不需要。常用應用程式清單由雲端每小時自動重新整理，新安裝應用程式即時納入候選，分流即時生效，無需升級 App、也無需中斷連線重新連線。

### Q：電腦端的「依據行程分流」是什麼意思？

除了圖形介面 App，電腦端還能辨識命令列工具、Homebrew / Node 等沒有安裝紀錄的獨立程式（依據行程名稱去重）。這樣像開發工具、指令碼這類沒有傳統「App 圖示」的程式也能單獨分流。
