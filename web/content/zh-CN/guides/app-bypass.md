开途最新一轮规则优化带来两项升级。第一，<strong>除 iPhone / iPad 外，电脑端（Mac / Windows / Linux）与安卓现已支持按应用、甚至按进程精准分流</strong>，可以把任意一个 App 一键强制「直连」；第二，<strong>针对微信、QQ、腾讯文档、腾讯会议等腾讯系应用做了专项归属优化</strong>，彻底解决这类「怕换 IP」的应用在代理下被风控、掉登录、消息延迟的老问题。常用应用清单由云端持续更新，<strong>无需升级 App、无需重连即可生效</strong>。

## 一、按应用 / 进程分流：任意 App 一键直连（iPhone / iPad 除外）

「分应用分流」让你为每个应用单独决定走代理还是直连。它有两层：

- <strong>智能模式（默认开启）</strong>：中国大陆应用——微信 / 支付宝 / 12306 / 主流银行——自动走直连，其余流量走代理，开箱即用，不用手动配置。
- <strong>按应用手动覆盖</strong>：把单个应用强制设为「直连」，覆盖当前区域的智能默认。适合会因代理 IP 触发风控的银行 App、网游等。
- <strong>电脑端支持到「进程」级</strong>：除已安装应用外，命令行工具、Homebrew / Node 等独立程序也能作为候选出现（按进程名去重，自动过滤系统进程），分流粒度更细。
- <strong>隐私守护</strong>：分流配置里的应用名永远不会出现在日志、反馈包或错误上报里。

<strong>为什么 iPhone / iPad 例外？</strong>iOS 系统不向 VPN 扩展开放「某条连接属于哪个 App」的归属信息，因此苹果设备上无法按应用挑选。但智能分流的<strong>按域名 / IP 的规则分流在 iOS 上照常工作</strong>——国内网站和服务依然自动直连，只是不能精确到单个 App。

## 二、腾讯系应用专项优化

腾讯系应用对网络出口格外敏感，过去在代理下最容易出问题。这次我们做了专项归属优化，<strong>已在 Mac / Windows / Linux / 安卓真机逐一验证</strong>。常见的几类坑：

- <strong>微信换 IP 被风控</strong>：代理出口频繁变化会触发登录保护、扫码失效、支付异常。智能模式让微信默认直连，用你真实的本地 IP。
- <strong>QQ 多进程 / 子模块嵌套</strong>：QQ 把腾讯文档等子模块嵌在应用包内，过去归属会漏判，导致本该直连的子进程走了代理。现已正确识别。
- <strong>腾讯会议 / 腾讯视频卡顿</strong>：这类应用走国内 CDN，绕代理直连更快更稳。
- <strong>Windows 上的 UDP / QUIC 漏归属</strong>：Windows 内核把这类 socket 记成通配地址，过去会整类漏掉；现已按精确地址匹配修复。

效果是：微信、QQ、腾讯文档、腾讯会议等<strong>稳定走直连，不再被代理 IP 拖累</strong>。如果你有特殊需求，也可以在「分应用分流」页面手动把任意腾讯系应用切换为「直连」或「智能」。

## 三、三步开启分应用分流

1. 打开开途客户端，展开<strong>「高级设置」</strong>，把<strong>路由模式</strong>设为<strong>「智能分流」</strong>（对应图 1 的 ①）。
2. 在<strong>「分流国家」</strong>选择你所在的区域，例如「中国」，或勾选「自动检测（根据 IP 位置）」（图 1 的 ②）。
3. 点<strong>「不走代理的应用」</strong>进入列表（图 1 的 ③）。默认全部跟随智能规则；需要时把某个 App 切到<strong>「直连」</strong>（图 2 的 ④）。

提示：连接 VPN 期间高级设置为只读，<strong>先断开再修改分流配置</strong>即可。

## 常见问题（FAQ）

### Q：iPhone / iPad 为什么不能按应用分流？

iOS 系统不向 VPN 扩展开放每条连接的应用归属信息，这是苹果的系统限制，不是开途的功能缺失。苹果设备上仍可使用按域名 / IP 的智能分流，国内网站和服务依然自动直连。

### Q：把微信设成「直连」安全吗？会暴露真实 IP 吗？

直连意味着微信用你本地的真实网络连接腾讯服务器，不经过代理——这正是微信期望的状态，能避免换 IP 触发的风控。微信本来就直连腾讯自家服务器，不存在额外隐私风险；反而强行走代理才更容易出问题。

### Q：「智能」和「直连」有什么区别？

智能 = 跟随当前区域的分流规则（国内应用直连、其余走代理），由云端规则库决定。直连 = 强制这个 App 永远不走代理。需要精确控制某个应用时用「直连」，其余保持「智能」即可。

### Q：新装的 App 需要重连才能生效吗？

不需要。常用应用清单由云端每小时自动刷新，新装应用即时纳入候选，分流即时生效，无需升级 App、也无需断开重连。

### Q：电脑端的「按进程分流」是什么意思？

除了图形界面 App，电脑端还能识别命令行工具、Homebrew / Node 等没有安装记录的独立程序（按进程名去重）。这样像开发工具、脚本这类没有传统「App 图标」的程序也能单独分流。
