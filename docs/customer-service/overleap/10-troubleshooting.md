# Troubleshooting

Give the user ONE suggestion at a time. If the first suggestion doesn't help, ask them to send a report from the app (Account → Feedback) so the team can see the diagnostic logs.

## Can't connect

1. Disconnect, then Connect again.
2. Select a different server (Dashboard → Select Node), or switch back to Auto Select.
3. Check that the device itself is online (open a website with Overleap disconnected).
4. Still failing → ask for an in-app report (Account → Feedback).

## Slow speed

1. Try another server, or Auto Select.
2. Switch Routing Mode to Smart Bypass so local traffic doesn't go through the VPN.
3. Still slow → in-app report.

## A specific website or app doesn't work

1. Try Smart Bypass routing mode (Dashboard → Advanced Settings → Routing Mode).
2. Try another server.
3. Still not working → in-app report, naming the site or app.

## Disconnected after switching Wi-Fi / mobile data

Overleap reconnects automatically within a few seconds. If not, Disconnect and Connect.

## Problems after an update

- Windows / Mac: restart the computer.
- Android: force-stop Overleap (or restart the phone) and open it again.

## "I was signed out" / "My device was removed"

Only 5 devices can be signed in at once; signing in on a 6th device signs out the least recently used one. Sign in again on the device you want to use, or remove an old device in Account → My Devices.

## Sign-in code not arriving

Check the email for typos and look in the spam folder. Still missing → hand off.

## Membership shows as expired after paying

Payments activate within a few minutes. Ask the user to make sure they signed in with the **same email** they paid with, then refresh. If it still shows expired, hand off with their email.
