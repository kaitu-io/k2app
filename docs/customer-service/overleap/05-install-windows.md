# Installing on Windows

Requirements: Windows 10 or 11, 64-bit.

## Steps

1. Open https://overleap.io/install on your PC and download the Windows installer (file name like `Overleap_0.4.11_x64.exe`).
2. Double-click the downloaded file.
3. If Windows asks "Do you want to allow this app to make changes to your device?", click **Yes**. (The installer needs administrator permission to set up the VPN service.)
4. Follow the installer. Overleap opens automatically when it finishes.
5. Sign in with your email and the code we send you, then click **Connect**.

## "Windows protected your PC" (SmartScreen)

This can appear for newly released versions. It's expected and safe:
1. Click **More info**.
2. Click **Run anyway**.

## The browser blocked the download

- Chrome: on the download warning, click **Keep**.
- Edge: in the downloads list, click the "···" next to the file → **Keep**.

## Updates

Overleap checks for updates automatically and shows "New version available — Update now". Click it to install the update.

## Closing the window

Closing the window keeps Overleap running in the system tray. To quit completely, right-click the tray icon → Quit.
