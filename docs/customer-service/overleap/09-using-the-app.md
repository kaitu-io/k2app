# Using the App

## Connecting

Open Overleap and tap/click **Connect** on the Dashboard. To stop, tap **Disconnect**.

## Choosing a server

- **Auto Select** (default) picks the best server for you.
- To choose one yourself: Dashboard → **Select Node**. Use **Refresh Node List** to reload the list.
- **Smart Switch in Same Country** automatically moves you to another server in the same country if yours has a problem.

Do not list or promise specific countries or cities — the server list in the app is the source of truth.

## Routing mode

Dashboard → Advanced Settings → **Routing Mode**. Disconnect first — the setting can't be changed while connected ("Please disconnect before modifying").

- **Global Proxy**: all traffic goes through Overleap.
- **Smart Bypass**: traffic to your chosen country goes direct (not through the VPN); everything else goes through Overleap. Pick the country under "Split Country", or use "Auto-detect (based on IP location)".

Tip: if a local site or app (for example your bank) doesn't work through the VPN, try Smart Bypass.

## Per-app routing

On platforms where it's supported, Dashboard → **Apps that bypass VPN** lets you set each app to Smart, Proxy, or Direct.

## Main sections of the app

- **Dashboard**: connect, server, routing mode
- **Purchase**: plans (not shown on Android — subscribe on overleap.io)
- **Account**: membership status and expiry date, devices, email and password, Feedback, Language Settings, Switch Account (sign out), Delete Account
- **Help**: frequently asked questions

## Network changes

When you switch between Wi-Fi and mobile data, Overleap reconnects automatically within a few seconds. If it doesn't, tap Disconnect and then Connect.
