# iPhone / iPad 安装指南

系统要求：iOS 16 及以上，iPhone 和 iPad 都支持。

## 安装步骤

1. 打开 App Store，搜索「开途」（也可以在 kaitu.io/install 点 App Store 链接）
2. 点击「获取」下载安装
3. 打开开途，输入邮箱 → 点「发送验证码」→ 输入验证码登录（也可以用密码登录）
4. 第一次点击连接时，系统会提示「"开途"想要添加 VPN 配置」，点「允许」，再验证面容 / 指纹 / 密码

## 在 App Store 搜不到

部分地区的 App Store 可能搜不到，请检查 Apple ID 的地区。还是找不到就转人工。

## 购买

建议在 kaitu.io/purchase 网页上购买，买完用同一个邮箱登录 App 即可。

## 更新

在 App Store 里更新。更新后如果出现异常，可以删掉 App 重新安装。

## 保持 VPN 常开

iPhone 上可以打开「保持 VPN 常开（Always On）」。打开后，如果要关闭 VPN，需要去系统设置里操作。
