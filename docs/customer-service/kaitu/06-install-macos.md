# macOS 安装指南

系统要求：macOS 12 及以上，Intel 和 Apple 芯片的 Mac 都支持。macOS 11 及更早的版本无法使用。

## 安装步骤

1. 在 Mac 上打开 kaitu.io/install，下载安装包（文件名类似 `Kaitu_0.4.12_universal.pkg`）
2. 双击打开 `.pkg` 文件
3. 点「继续」→「安装」，输入 Mac 开机密码（用来设置 VPN 服务）
4. 安装完成后开途会自动打开
5. 用邮箱登录，点击连接

## 也可以用终端安装

打开「终端」，粘贴下面这行并回车，按提示输入开机密码：
`curl -fsSL https://kaitu.io/i/k2 | sudo bash`

## 提示"无法打开"或被系统拦截

安装包已经过苹果公证，一般不会出现。如果出现：
1. 打开「系统设置」→「隐私与安全性」
2. 往下滑，点击开途相关提示旁的「仍要打开」
3. 输入开机密码

## 打开时要求输入开机密码

如果后台服务没有在运行，开途会请求一次管理员密码来恢复服务，这是正常的。

## 更新

开途会自动检查更新，下载好的更新会在下次退出并重新打开时生效。重新安装新版 `.pkg` 也可以直接覆盖升级。
