# 开途产品概览

## 开途是什么

开途是一款网络加速 VPN 应用，帮助用户稳定、快速地访问海外网络。

核心技术：
- **k2v5 协议 + ECH**：加密握手，连运营商也看不到你访问的是哪个网站。
- **k2cc 拥塞控制**：在拥堵、丢包的网络上依然保持速度（越拥堵，越从容）。
- **QUIC / TCP 自动切换**：一种线路不通时自动换另一种。

## 支持的平台

| 平台 | 系统要求 | 获取方式 |
|---|---|---|
| Windows | Windows 10 / 11（64 位） | kaitu.io/install 下载 |
| macOS | macOS 12 及以上（Intel 和 Apple 芯片都支持） | kaitu.io/install 下载 |
| Linux | 使用 systemd 的主流发行版（amd64 / arm64） | 终端一条命令安装（见 Linux 安装指南） |
| iPhone / iPad | iOS 16 及以上 | App Store 搜索「开途」 |
| 安卓手机 | Android 7.0 及以上 | kaitu.io/install 下载安装包（不在 Google Play 上架） |

一个账号所有平台通用，最多 5 台设备同时登录。

## 两种模式

- **全局代理**：所有流量都走开途。
- **智能分流**：国内网站和应用直连，海外走开途（默认推荐）。

在主页「高级设置」里切换，切换前需要先断开连接。

## 开始使用的流程

1. 在 kaitu.io/install 下载并安装（iPhone 在 App Store 下载）
2. 用邮箱登录（验证码或密码）
3. 购买套餐
4. 点击连接按钮

## 没有免费试用

开途没有免费试用，需要购买套餐后才能使用节点。

## 产品线

- **开途 App**：本知识库的主要内容。
- **开途路由器版**：给全家所有设备用的路由器，见「路由器版」一篇。
