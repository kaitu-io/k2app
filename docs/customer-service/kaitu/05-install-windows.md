# Windows 安装指南

系统要求：Windows 10 / 11，64 位。

## 安装步骤

1. 在电脑上打开 kaitu.io/install，下载会在 5 秒后自动开始（没开始就点「备用下载」）
2. 下载的文件名类似 `Kaitu_0.4.12_x64.exe`
3. 双击运行，Windows 会问"你要允许此应用对你的设备进行更改吗？"，点「是」（安装需要管理员权限来设置 VPN 服务）
4. 按提示完成安装，安装完开途会自动打开
5. 用邮箱登录，点击连接

## 浏览器拦截下载

- Chrome：在下载提示上点「保留」
- Edge：在下载列表里，点文件旁边的「···」→「保留」

## Windows 提示"已保护你的电脑"（SmartScreen）

新版本刚发布时可能出现，这是正常的，不是病毒：
1. 点击「更多信息」
2. 点击「仍要运行」

开途安装包已经过代码签名。

## 关闭窗口 ≠ 退出

点窗口的关闭按钮只是隐藏到右下角托盘，VPN 仍在运行。要完全退出：右键托盘图标 →「退出」。

## 更新

开途启动后会自动检查更新，有新版本时会提示「新版本可用 / 立即更新」，点击即可自动安装。
