# 安卓安装总览

系统要求：Android 7.0 及以上。

开途安卓版不在 Google Play 上架，需要从官网下载安装包。

## 推荐方式：手机直接下载

1. 用手机浏览器打开 kaitu.io/install，下载会在 5 秒后自动开始（没开始就点「备用下载」）
2. 下载完成后点击安装
3. **建议先打开飞行模式再安装**，可以避免很多手机的安全检查拦截
4. 安装完成后关闭飞行模式，打开开途，用邮箱登录

不同品牌手机的拦截处理方法，见「各品牌安卓安装」一篇。

## 华为手机注意

HarmonyOS 5.0 及以上（NEXT）无法安装安卓应用，建议换一台设备。HarmonyOS 4.x 及以下可以正常安装。

## 手机上装不上：用电脑帮忙装

在电脑上安装开途桌面版（Windows、Mac、Linux 都可以），然后进入「账户」→「其他设备安装」→「安卓手机安装」，用数据线连接手机即可。详见「通过电脑 USB 辅助安装」一篇。

## 第一次连接

第一次点击连接时，系统会弹出 VPN 连接确认，点「允许」/「确定」。

## 更新

开途每次打开时会自动检查更新，有新版本会提示您更新。
