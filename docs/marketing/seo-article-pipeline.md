# 开途 SEO 精品文章：流程与逐篇规划（2026-11-10）

适用于 kaitu.io `/zh-CN/guides/*` 及以后的外语指南。写作格式与发布步骤以 `kaitu-content` skill 为准；本文管**写什么、怎么做成精品、怎么判断有没有用**。规则来源：David 2026-11-10「每篇要打造精品，不要泛泛地做」，以及记忆 `feedback_seo_content_premium_and_no_ai_ban_promises`。

## 一、语言策略：一个题目只写给真正会搜它的那种语言的读者

- **翻译不会提高中文页的排名。** 搜索引擎按语言分开排名，hreflang 只负责把读者分到对应语言的版本，英文版不会给中文版加分。
- 所以默认**单语言**：中国人搜的题目（快连、谷歌学术镜像、Instagram 网页版……）只写 zh-CN。
- 只有当某个题目**在另一种语言里确实有人搜**时，才写那种语言的版本，而且要按那种读者的处境原创，不直译。例：`letsvpn` 英文 90 天 8,111、`astrill vpn` 1.06 万（Bing 全球）。
- 繁体（zh-TW / zh-HK）不主动补：台湾、香港读者不需要这类工具，缺失时页面会自动回落到简体。
- 外语页面等 k2app-6e 的语言分支合进 main 之后才能发；韩语、俄语的真实量要用 Naver / Yandex 查，Bing 会严重低估。

## 二、选题门槛：三条都满足才进入写作

1. **有人搜**：主词 Bing 中国区 90 天精确曝光 ≥ 1,000（或一组近义词合计 ≥ 2,000）。只查一种写法会漏——同一意思换写法量可以差几十倍，各写法逐个查。
2. **搜的人需要我们**：读者卡住的那一步，正好是「网络打不开 / 不稳定」。只是找别人官网、找下载的导航词不做（例：「良心云官网」）。
3. **我们能拿出别处没有的东西**：一手实测、自己整理的对照表、官方原文核对。拿不出就不写。

不写：竞品「不好用 / 跑路」页（事实不稳、违反不贬低友商的规矩；对方**正式公告停服**时例外，按快连那篇的做法跟进）；版权灰色题目（Sci-Hub）；国内本来就能打开的网站（Overleaf）。

## 三、每篇的流程（每一步有交付物，过了才进下一步）

| # | 步骤 | 交付物 | 过关标准 |
|---|---|---|---|
| 1 | **立项卡** | 本文第五节的一张卡 | 主词与量、读者卡在哪、我们独有的东西、红线都写清楚 |
| 2 | **调研** | `research/<slug>.md`（Gemini Deep Research）+ `research/<slug>-verify.md` | 报告里每个要用的事实都点开原始链接核对；核不实的不用 |
| 3 | **一手实测** | 实测记录（截图、时间、网络环境） | 用测试机房的大陆出口实际打开 / 安装一遍；凡是「能 / 不能」的说法都有当天实测 |
| 4 | **提纲评审** | 提纲 + 每节要用的证据 | 首句直接给答案；有一张自己整理的对照表；「官方说明 / 实测 / 社区经验」分开写 |
| 5 | **初稿** | `web/content/zh-CN/guides/<slug>.md`（`draft: true`） | 符合 `kaitu-content` 质量门；正文 0 个裸「Kaitu」；不贬低友商 |
| 6 | **独立核稿** | 核稿意见 | 另起一个不看过程的代理，只拿稿子和 verify 文件，找「哪句话没有证据 / 会过时 / 有误导」 |
| 7 | **渲染检查** | 本地页面截图（桌面 + 手机宽度） | 表格、FAQ、链接、下载按钮都正常 |
| 8 | **David 审** | 线上预览链接 + 要点 | David 确认后才改 `draft: false` |
| 9 | **发布** | 合并、部署、线上核对 | 页面 200、canonical 指向自身、在 sitemap 里；GSC 请求编入索引 |
| 10 | **复盘** | 增长台账一行 | 第 4 周、第 8 周：曝光、排名、点击率、「指南转化」漏斗里的下载 / 注册 / 付款 |

节奏：**同时最多两篇在写**，一篇过了第 8 步再开下一篇。宁可一周两篇好的，也不要一周十篇平庸的——国际学校那 10 篇就是批量写的，合计约 30 次阅读、0 次注册。

## 四、每篇都要有的转化设计（信任在前，比较自然）

1. **首段直接回答**读者的问题（官方入口是哪个、国内能不能直接打开），不卖东西。
2. **讲清原因**：为什么打不开 / 为什么镜像总失效——让读者觉得「这篇懂行」。
3. **一张办法对比表**：镜像站 / 免费工具 / 机场 / 开途，各列优点和缺点，**开途的缺点也写**（要付费、没有永久免费版）。读者自己比较后再做选择。
4. **两个下载入口**：对比表下方一个，文末一个。文字用「免费试用 / 下载」，不用「立即购买」；链接带 `utm_source=guide&utm_campaign=<slug>`。
5. **FAQ** 用 Bing 上的真实问法。
6. 涉及 AI 平台账号：只讲公开原理，不承诺不封号，不展示我们节点的 IP 检测分数；封号 / IP 纯净度话题链接到 k2app-32 负责的两篇，不在本系列展开。

## 五、逐篇立项卡（按优先级）

数据均为 Bing 中国区 zh-CN、2026-08-12 至 11-09 的 90 天精确曝光。

### 1. 谷歌学术镜像入口为什么总失效？（论文人群）

- **暂定 slug**：`google-scholar-mirror`
- **主词**：谷歌学术镜像入口 143,489 · 谷歌学术镜像官网 23,656 · 谷歌学术镜像网站 22,130 · 谷歌学术官网 12,149 · google scholar 镜像网站 15,153 · 谷粉学术 70,292（品牌词，只作说明对象）
- **读者卡在哪**：镜像站隔一阵就打不开，要反复找新地址；有的要登录、有的满屏广告，不知道哪个安全。
- **我们独有的东西**：**连续 7 天实测 15–20 个常见镜像站的可用率**（大陆出口每天定时打开一次），做成一张「镜像站可用率表」；对比镜像和官方站的功能差异（引用导出、提醒、个人图书馆、全文链接）。
- **证据清单**：Google Scholar 官方功能说明；镜像的工作原理（反向代理）与风险（登录凭据、注入广告）；实测记录。
- **红线**：不推荐具体镜像站，不贴需要登录的镜像地址；不提供 Sci-Hub 一类内容。
- **转化切入点**：「每周换一次镜像」vs「直接用官方站」的时间成本。

### 2. Instagram 网页版入口与国内访问（女性 / 社交人群）

- **暂定 slug**：`instagram-web-china`
- **主词**：instagram 270,840（导航，接不住）· instagram网页版 60,243 · instagram官网 28,436 · instagram下载 21,821 · ins官网 4,620 · instagram网页版登录入口 3,520 · instagram注册 674 · ins怎么注册 179
- **读者卡在哪**：官方地址是哪个、网页版和 App 的区别、为什么打开转圈、注册时收不到验证码。
- **我们独有的东西**：大陆实测（直连 / 常见失败表现截图）；网页版与 App 的功能对照表（发帖、快拍、私信、Reels）；注册时手机号 / 邮箱验证的官方说明。
- **红线**：不教规避 Instagram 的风控；不出现第三方「ins 查看器」推荐。
- **转化切入点**：图片和视频多，晚高峰对速度要求高——自然引出「稳定」的需求。

### 3. Pinterest 国内怎么用（女性 / 设计灵感人群）

- **暂定 slug**：`pinterest-china`
- **主词**：pinterest 282,975 · 其余长尾待逐个查（pinterest官网、pinterest网页版、pinterest下载、拼趣）
- **读者卡在哪**：做设计、找穿搭灵感、写小红书配图时要用，国内打不开；有国内「同类站」但内容不同。
- **我们独有的东西**：实测 + Pinterest 与国内同类平台（花瓣、小红书、站酷）的内容差异表，帮读者判断「是不是非用 Pinterest 不可」。
- **待办**：先补齐长尾数据再立项。

### 4. Claude Code 安装：国内网络这一步怎么过（开发者）

- **暂定 slug**：`claude-code-install-china`
- **主词**：claude code安装 41,715 · claude code安装教程 6,058 · claude code使用教程 10,100 · claude code下载 6,682 · claude code桌面版 6,216 · claude cli安装 1,161（claude code 262,070 / 官网 145,768 为导航词，接不住）
- **读者卡在哪**：安装脚本 / npm 包下载失败、登录时浏览器授权页打不开、终端里走不走代理。
- **我们独有的东西**：大陆网络下逐步实测安装（官方安装方式各走一遍），记录每一步卡在哪个域名；一张「安装各步骤需要访问的域名 × 国内直连能否打开」表。
- **证据清单**：Anthropic 官方安装文档、支持地区说明。
- **红线**：开头写明 Anthropic 官方支持的地区不包括中国大陆；只讲网络连接，不讲账号注册技巧，不承诺不封号；封号 / IP 话题链接到 k2app-32 的文章。
