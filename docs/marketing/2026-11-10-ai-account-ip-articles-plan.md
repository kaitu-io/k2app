## 两篇文章

### 文章 A：Claude 账号为什么会被封？（官方说明与常见情况）

- 暂定 slug：`claude-account-suspended-reasons`
- 主词：claude封号 / claude 封号 / claude封号原因 / claude账号被封；次要：chatgpt封号
- 开头先给结论：官方怎么说、常见触发情境有哪几类、被封后能做什么（申诉、数据、退款）。
- 提纲（Gemini 报告到了再定稿）：
  1. 一句话答案 + 官方条款原句（支持地区、使用政策）
  2. 官方明确说过的因素 vs 社区猜测的因素（对照表，各附出处）
  3. 社区常见的几类案例（标明是个人经验）
  4. 被封之后：申诉入口、数据导出、订阅退款的官方说法
  5. 和 ChatGPT、Gemini 的地区限制对照（简短）
  6. FAQ（取自 Gemini 第 7 题，挑真实问法）
- 与开途的连接点：只在文末说明「网络稳定是使用海外服务的前提，平台规则由用户自行遵守」，链接 `/install`，不写任何承诺。

### 文章 B：IP 检测 / IP 纯净度到底在测什么？

- 暂定 slug：`ip-purity-check-explained`
- 主词：ip纯净度查询 / ip纯净度检测 / ip检测 / claude ip检测 / 节点纯净度测试
- 开头先给结论：这些检测站看的是哪几类数据、分数怎么读、为什么分数高也不代表安全。
- 提纲：
  1. 一句话答案
  2. 检测站依据的数据（ASN 类型、代理库、欺诈分、黑名单、同 IP 用户数、地理一致性、DNS / WebRTC 泄漏、时区语言）——表格
  3. 主流检测站各自看什么、怎么读分（ippure、ping0、ipinfo、Scamalytics、IPQS 等），**只讲原理，不排名、不贴我们的分数**
  4. 常见误解：「纯净度高就不封」「住宅 IP 一定安全」——有没有证据表明 AI 平台用这些分数
  5. FAQ
- 品牌词（ippure、ping0）只作为说明对象出现，不做导航页。
